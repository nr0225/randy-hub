# Cloudflare Pages 公開站

這個資料夾只放 Randy Hub 的公開、非商業 OSS 介紹頁，不包含私人 Strategist 狀態、記憶、Runtime DB、API 金鑰或客戶資料。

Cloudflare Pages 設定：

- Production branch：`main`
- Framework preset：None
- Build command：留空
- Build output directory：`site`

先使用 Cloudflare 提供的 `*.pages.dev` 網址驗收。確認部署正常後，才把 `randy.is-a.dev` 以 custom subdomain 方式接上；DNS 變更必須保留既有 Mail 與驗證記錄。

本頁定位為開發者／開源專案展示，不作商業 storefront。
